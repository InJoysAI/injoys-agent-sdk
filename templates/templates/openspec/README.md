# OpenSpec-ish Templates (Specflow)

These templates are used by `design/context-dev/tools/specflow/specflow.mjs` and referenced by Context-Dev OpenSpec integration docs.

Files:
- `proposal.md.template`
- `spec.md.template`
- `design.md.template`
- `tasks.md.template`（`change_kind` 为 `code` / `mixed`）
- `tasks-docs-ops.md.template`（`change_kind` 为 `docs-ops`：不涉及业务代码的文档/配置/运维/核对类变更）

Note: This project keeps the directory layout under `openspec/` (changes/specs) but does **not** depend on the upstream `openspec` CLI.
