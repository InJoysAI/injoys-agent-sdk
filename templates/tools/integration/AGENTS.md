# Integration 幂等增强指令

> 当被 `.agent/workflows/context-openspec.md`（或其子命令）调用时执行，用于保证 `.context/openspec/integration.md` 存在并保持“资产索引区块”最新。

---

## 🎯 执行指令

依次执行以下步骤：

---

### Phase 1: 确保 integration.md 存在

检查目标项目 `.context/openspec/integration.md` 是否存在：

| 条件 | 操作 |
|------|------|
| 不存在 | 先创建 `.context/openspec/` 目录（若不存在），再从 `@design/context-dev/templates/openspec/integration.md.template` 复制到 `.context/openspec/integration.md` |
| 已存在 | 跳过复制，进入 Phase 2 |

---

### Phase 2: 刷新 CONTEXT_ASSET_INDEX 区块

在 `.context/openspec/integration.md` 中：

1. **定位区块**：
   ```
   <!-- CONTEXT_ASSET_INDEX:START -->
   ...
   <!-- CONTEXT_ASSET_INDEX:END -->
   ```

2. **从 Manifest 读取资产**：
   - 读取 `.context/context-manifest.json`
   - 从 `generated_files` 节点按 scope 获取文件列表

3. **动态生成区块内容**：
   ```markdown
   <!-- CONTEXT_ASSET_INDEX:START -->
   > Generated by `.agent/workflows/context-openspec.md`. Do not edit manually.
   
   - **Required**:
     - `.context/README.md`
     - `.context/AGENTS.md`
     - `.context/criterion.md`
     - `.context/context-manifest.json`
   - **Architecture** ({{N}} 个文件):
     {{从 generated_files.architecture 动态列出}}
   - **Domain** ({{N}} 个文件):
     {{从 generated_files.domain 动态列出}}
   - **DB** ({{N}} 个文件；键不存在或为空则整行省略):
     {{从 generated_files.db 动态列出}}
   - **UI** ({{N}} 个文件；键不存在或为空则整行省略):
     {{从 generated_files.ui 动态列出}}
   - **Legacy** ({{N}} 个文件；键不存在或为空则整行省略):
     {{从 generated_files.legacy 动态列出}}
   - **OpenSpec** ({{N}} 个文件，派生产物，不作为 Context 输入):
     {{从 generated_files.openspec 动态列出；路径原样写出，含项目根的 `openspec/...` 条目}}
   <!-- CONTEXT_ASSET_INDEX:END -->
   ```

   > ⚠️ 只改区块内容，保持幂等与可审计

---

## ⚠️ 保护规则

- 每次只更新 ASSET_INDEX 区块，不改区块外的内容
- 区块**内**的条目随 Manifest 变化是预期行为（例如 `project` / `plan` 生成后，OpenSpec 一栏会多出根目录条目），不属于违反本规则

---

### Phase 3: 登记集成资产

执行 `@design/context-dev/tools/manifest/AGENTS.md`（mode: update），确保 `generated_files.openspec` **包含** `.context/openspec/integration.md`：

```json
"generated_files": {
  "openspec": [
    ".context/openspec/integration.md"
  ]
}
```

口径以 `tools/manifest/AGENTS.md`「`generated_files.openspec` 的登记口径」为准：该键同时登记其他模块的产出（项目根的 `openspec/config.yaml`、`openspec/proposal-roadmap*.md`）。本模块**只登记自己的 `integration.md`**，**不得覆盖、重排或删除其他模块已登记的条目**；`openspec/changes/**`、`openspec/specs/**` 不登记。重复执行不得产生重复项。

---

## ✅ 完成后

报告结果：

```
=== Integration 幂等增强 ===
✅ .context/openspec/integration.md (存在/已复制)
✅ CONTEXT_ASSET_INDEX 区块已刷新
✅ generated_files.openspec 已登记且无重复项
```
